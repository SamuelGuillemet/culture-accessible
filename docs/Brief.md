2 / Construction de chaque page

Page d’accueil :

présenter avec un petit texte le projet -> call to action vers le formulaire de contact
avoir un espace “les derniers épisodes” -> avec un call to action qui renvoie vers la page Podcast
avoir un espace “on répond avec vos question” -> avec un call to action qui renvoie vers la page Ressources

Page Podcasts :

Cette page doit permettre d’écouter les différents épisodes. A terme, ils seront au format Youtube, sous-titrés. Pour l’instant, ce n’est pas le cas.
-> Prévoir encarts vidéos ET encarts audio

Audi dispo via spotify, passage de l'id et Iframe pour l'intégration sur le site

Pour chaque épisode il doit y avoir :
un espace titre de l’épisode
un court texte descriptif
le format audio ou vidéo de l’épisode

Pour la présentation : ça peut être sous forme de cards, et quand on clique dessus,un encart pour l’épisode apparaît

Pour chaque card :
prévoir un espace délimité
un espace texte pour le titre de l’épisode
un espace texte pour le nom de l’épisode
rendre la card cliquable

Page Ressources :

Le but -> on va isoler des bouts d’épisodes qui soulèvent une question, un enjeu
et on y répondra sous forme d’article

Il faut :
un titre pour présenter la thématique
un encart audio pour diffuser l’extrait du podcast -> on utilise le timesatmp en secondes pour indiquer le point de départ de l’extrait
un espace texte pour répondre à la question
un call to action pour découvrir l’épisode en entier (qui renvoie ainsi vers la page Podcast, à l’épisode en question)

Page contact :

ça serait bien d’encastrer le formulaire de contact dans le site internet, si c’est possible ? embed le google form directement.

Ou alors :
un espace texte pour expliquer le but (on reçoit les demandes pour participer au contact)
et on met un call to action vers notre Google farm (à ouvrir dans une page différente)
